# Contribuição

Este é um portfólio pessoal. Mudanças devem preservar a identidade visual, a navegação acessível e a precisão das informações dos projetos. Antes de propor uma alteração, consulte `PROJECT.md`, `docs/BUSINESS_RULES.md` e `docs/ENGINEERING.md`. Use npm, rode `npx tsc --noEmit` e `npm run build`, e revise o resultado em desktop e celular.
